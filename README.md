# Rent a Car API

Početni Node.js projekt izgrađen pomoću Expressa.

## Pokretanje

Potrebni su Node.js i npm.

```bash
npm install
npm run dev
```

Server se pokreće na `http://localhost:3000`. Port se može promijeniti varijablom okruženja `PORT`.

## Dostupne rute

- `GET /` — osnovna poruka API-ja
- `GET /health` — provjera dostupnosti servera
